# Site Blocker — Do the Task

A Chrome extension that intercepts visits to distracting sites and redirects you to complete a quick task first.

## Install

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked**
4. Select the `site-blocker-extension` folder

## How it works

- When you navigate to a blocked site during blocked hours, the extension intercepts the page and shows you a task
- Complete the task to proceed to the site
- Skip the task and the site is locked for 5 minutes
- Manage blocked sites, tasks, and schedule from the extension popup

## Defaults

- **Blocked hours:** 10:00 AM – 5:00 PM
- **Blocked sites:** Instagram, Twitter/X, Reddit, TikTok, YouTube, Facebook
- **Tasks:** Push-ups, drink water, stretch, gratitude list, clean desk, text someone, close tabs, deep breaths

All configurable from the popup.
